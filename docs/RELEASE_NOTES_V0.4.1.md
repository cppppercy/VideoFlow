# VideoFlow v0.4.1

## 修复

- 修复西交 LMS 回放在 FFmpeg 阶段常见的 HTTP 403：优先使用 `download_url`，并添加平台播放器使用的 `Origin` 与 `Referer`。
- 主音源失败后自动尝试其备用地址及其他机位；不会在错误中输出带签名 URL。
- 将媒体失败细分为 401、403、404、无音轨和清单/分片读取失败。

## 性能与识别

- 增加快速、均衡、高精度三档；使用 faster-whisper 批量推理。
- 增加课程关键词输入，用于提示人名、术语和英文缩写。
- 批量推理启用词级时间戳，并按停顿、句末和最长时长重新切分，避免生成约 30 秒的大块 SRT。
- 模型继续缓存，模型加载和推理继续串行，避免普通电脑并发耗尽内存。

## 界面

- 顶层入口由五个收敛为“本地文件、在线内容、兼容录音”三个。
- B 站已有字幕、B 站音频和西交 LMS 在“在线内容”中分组。
- 所有需要语音识别的入口共用一套速度、语言和关键词设置。

## 验证

- 36 项自动化测试通过。
- Python 编译、依赖检查、浏览器助手 JavaScript 语法和 Gradio 页面构造通过。
- 经授权 5 分 56 秒中文视频：自动分段后的快速档约 14.46 秒、48 段，最长分段 8 秒；旧版 tiny 路径约 37.52 秒。该数据只验证速度与输出完整性，不是准确率基准。
- LMS 修复依据用户真实 403 失败和当前可用客户端的媒体请求行为完成；修复后的真实课程仍需用户登录态复验。
