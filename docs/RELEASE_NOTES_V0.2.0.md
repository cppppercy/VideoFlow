# v0.2.0 发布准备

## 本版新增

- B 站单视频已有字幕导入（仅完整 BV HTTPS 链接）。
- BCC JSON 字幕转换为现有 `Transcript` 数据模型，复用 TXT/SRT 导出。
- 可选使用用户明确选择的本机 Chrome/Edge B 站登录会话；不保存、上传或导出 Cookie。
- 链接请求总超时 45 秒；无登录、无字幕、无效链接和网络失败均返回可读错误。
- 跨平台安全导出文件名。

## 明确不包含

- 完整视频下载、DRM/登录绕过、Cookie 文件管理、课程平台自动登录、批量链接、其他网站链接。
- B 站登录态成功导入的自动化或真实验收；需要用户在本机网页中主动选择浏览器完成。

## 验证

- pytest：16 项通过。
- 编译与 Gradio 页面构造通过。
- 真实 B 站公开链接无登录请求返回受控“需要登录/本地文件回退”错误；未下载完整视频。
