# VideoFlow v0.4.0 发布说明

## 新增

- B 站独立音频转录：不要求视频已有字幕，不需要实时播放。
- 最多 10 个 B 站 BV 链接的队列处理与 TXT/SRT ZIP 导出。
- Whisper 模型单实例缓存，降低连续任务的重复加载成本。
- 西交 LMS 本地浏览器助手：在用户当前登录权限内生成单个活动的短期转录任务。
- LMS 回放的最佳音频流选择、临时音频提取和本地转录。

## 安全边界

- B 站只选择 `bestaudio`，没有音频流时失败，不回退完整视频。
- LMS 扩展不读取或导出 Cookie、账号、密码；短期 token、Bearer token 和签名 URL 不写文件、不打印、不提交。
- 只处理当前账号已获准观看的回放；无权限、过期、无音轨或 DRM 均停止。
- 所有临时音频在对应工作流结束后清理。

## 已验证

- 31 项离线自动化测试通过（文档完成前的阶段结果，最终数量以 `docs/STATUS.md` 为准）。
- 用户提供的 B 站 10 分 44 秒公开视频在无 Cookie 条件下，仅获取约 11.8 MB 独立音频并以 `tiny` 模型生成 147 个中文分段。
- LMS 浏览器登录态与真实课程回放尚需用户本机验收，不能表述为已成功。
