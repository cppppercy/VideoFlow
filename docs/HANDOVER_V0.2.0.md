# VideoFlow v0.2.0 版本交接报告

报告日期：2026-10-16。本报告仅描述已实现和已验证的事实。

## 版本与基线

- 版本：`0.2.0`。
- 分支：`main`。
- 本轮功能在提交完成后以最新 `main` 为基线；推送、标签和 Release 均须负责人另行批准。

## 已实现

- 保留 V0.1 的本地媒体 Whisper 转录、Gradio 预览、TXT/SRT 下载和 CLI。
- 新增 B 站已有字幕模式：只接受白名单内的单个 BV HTTPS 链接，yt-dlp 只写字幕 JSON，不下载完整视频。
- BCC 字幕解析后复用统一 `Transcript`、SRT/TXT 导出与结果预览。
- 页面提供中文、英文、任意字幕语言选项；用户可选“不使用登录”或显式选择 Chrome/Edge 登录会话。
- 西交 LMS 课程 URL 会被明确拒绝，并指向合规的本地文件转录回退。

## 已验证

- 16 项自动化测试通过：V0.1 回归、时间码/导出、链接校验、LMS 回退、BCC 解析和字幕下载命令安全选项。
- `compileall` 与 Gradio 页面构造通过。
- 真实 B 站公开视频在无登录状态下返回明确的登录/本地文件提示，未下载视频；请求受 45 秒硬超时限制。

## 未验证与限制

- 尚未在用户已登录的 B 站浏览器会话中真实成功导入字幕，因此不得称其“已真实导入成功”。
- B 站字幕可访问性由平台、账号和视频决定；无字幕或需登录时应用不会改为下载视频转录。
- LMS 课程回放自动导入不支持，也不会绕过学校登录或课程访问限制。
- `base`/`small` Whisper 的速度和质量、Python 3.11、异常退出后的临时导出目录清理仍未验证。

## 关键约束

- 保持 `av>=11,<19`；faster-whisper 1.x 与 PyAV 19 在真实媒体上不兼容。
- 在线 URL 必须先校验域名和 BV 路径，禁止任意 URL 下载。
- 不持久化浏览器 Cookie，不提交媒体、模型缓存、导出文件或敏感数据。
- 后续版本应先选择一个单一目标，不要在未规划时加入登录、批量、云端、翻译、摘要或课程平台抓取。
