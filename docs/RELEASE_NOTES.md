# v0.1.0 发布准备

## 本版内容

- 本地音频/视频转录，默认 CPU INT8。
- 自动识别语言，或手动指定中文、英文、日文、韩文。
- 分段时间戳预览、全文复制、UTF-8 TXT 与标准 SRT 下载。
- 本机 Gradio 网页与命令行入口。

## 已验证

- 授权中文 MP4 使用 `tiny` 模型完成真实转录，生成 120 段字幕以及 TXT/SRT。
- 7 项单元测试通过；项目依赖检查通过。
- 本机网页服务仅监听 `127.0.0.1`，不默认公开分享。

## 已知限制

- `tiny` 适合快速初稿；同音字与专业术语可能误识别。`base`、`small` 尚未在同一验收视频上完成速度与质量对比。
- 首次使用模型会下载权重，CPU 转录耗时取决于媒体时长和机器性能。
- 未提供说话人区分、翻译、在线视频下载、批量队列或云端同步。

## 依赖许可证核对

以本次安装的直接依赖元数据为准：`faster-whisper 1.2.1` 为 MIT、`gradio 6.30.0` 为 Apache-2.0、`av 18.1.0` 与 `httpx 0.28.1` 为 BSD-3-Clause。项目自身采用 MIT；发布新版本前应再次核对实际锁定版本及其许可证。
