# VideoFlow 产品定位

VideoFlow 是由学生发起的长期个人开源项目，先服务个人实际需要，再逐步面向需要获取视频内容的普通用户和学习用户。

## 长期方向

- 轻量、低成本、可扩展的视频内容提取工具。
- 以本地处理和免费开源技术为优先，避免无必要的服务器与 API 成本。
- 后续可能探索课程学习整理、PPT/画面内容提取与 AI 内容整理，但每一项都应独立评估需求、成本和隐私影响。

## 当前边界

V0.1 只处理用户本机提供的音频或视频：转录为带时间戳的文字，预览并导出 TXT/SRT。它不下载在线视频、不上传文件、不提供云端账户，也不试图在第一版解决全部内容整理需求。
