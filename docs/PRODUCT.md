# VideoFlow 产品定位

VideoFlow 是由学生发起的长期个人开源项目，先服务个人实际需要，再逐步面向需要获取视频内容的普通用户和学习用户。

## 长期方向

- 轻量、低成本、可扩展的视频内容提取工具。
- 以本地处理和免费开源技术为优先，避免无必要的服务器与 API 成本。
- 后续可能探索课程学习整理、PPT/画面内容提取与 AI 内容整理，但每一项都应独立评估需求、成本和隐私影响。

## 当前边界

V0.4.4 处理四种输入：本机音视频、B 站已有字幕、B 站独立音频流，以及由本地浏览器助手在用户当前 LMS 权限内生成的短期课程回放任务。Windows 默认扬声器回环录音保留为兼容性兜底。所有语音识别入口共用 CPU 快速、CPU 均衡、可选 NVIDIA GPU turbo 增强和 CPU 高精度设置；课程术语通过 hotwords 提示，并统一输出简体中文的带时间戳文字、自然段 TXT 和标准 SRT。长媒体自动使用 5 分钟重叠分块、块内批量识别；GPU 会按显存采用保守批量并在显存不足时回退，诊断展示实际批量、当前进程显存峰值、可疑字幕数量和覆盖检查。用户可选择仅精修少量模型标记为低置信或异常重复的片段。B 站音频单条成功结果直接进入通用结果区，多条成功结果才导出 ZIP。

B 站快速转录只选择独立音频格式，不以完整视频兜底。LMS 助手不读取或导出 Cookie、账号和密码，只在用户点击后复制单个活动的一次性播放器任务；Python 端不自动登录，不持久化任何 token 或带签名播放地址。遇到无权限、过期任务、无音轨或 DRM 时停止，不尝试绕过。
