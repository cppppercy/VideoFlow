# VideoFlow 产品定位

VideoFlow 是由学生发起的长期个人开源项目，先服务个人实际需要，再逐步面向需要获取视频内容的普通用户和学习用户。

## 长期方向

- 轻量、低成本、可扩展的视频内容提取工具。
- 以本地处理和免费开源技术为优先，避免无必要的服务器与 API 成本。
- 后续可能探索课程学习整理、PPT/画面内容提取与 AI 内容整理，但每一项都应独立评估需求、成本和隐私影响。

## 当前边界

V0.3 处理三种输入：用户本机提供的音频/视频、B 站单视频中当前用户可访问的已有字幕，以及用户正常播放时由 Windows 默认扬声器输出的本机声音。三者都会统一为带时间戳的文字并导出 TXT/SRT。链接模式不下载完整视频、不绕过登录/付费/DRM，也不支持课程平台自动登录；播放声音模式不读取课程链接、账号或浏览器 Cookie，且必须由用户确认拥有记录权限后手动启停。
