# VideoFlow

VideoFlow 是一个优先本地运行的视频/音频转文字工具。V0.3 提供本地媒体转录、B 站单视频已有字幕导入，以及播放中的电脑声音录制转写；结果可带时间戳预览并导出 UTF-8 TXT、标准 SRT 字幕。

它面向希望快速获取视频内容的个人用户，也为后续学习整理、课程内容提取等能力保留扩展空间。不会上传媒体到服务器，也不会默认开启公网分享。

## 功能

- 使用 `faster-whisper` 转录本地音频和常见视频文件
- 导入 B 站单个 BV 视频中当前账号可访问的已有字幕；不会下载完整视频
- 默认 CPU `int8` 推理；可选 tiny、base、small 模型
- 自动识别语言，也可指定中文、英文、日文或韩文
- 网页中查看每段开始/结束时间与文字
- 导出 UTF-8 编码 TXT 和标准 SRT
- 命令行入口，便于排查和自动化使用

## 安装

需要 Python 3.11–3.13 和已安装的 [FFmpeg](https://ffmpeg.org/)（本机已经能在命令行执行 `ffmpeg -version`）。首次转录会下载所选 Whisper 模型；模型大小和耗时随模型选择及机器性能变化。

```powershell
git clone <你的 GitHub 仓库地址>
cd VideoFlow
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
```

## 使用

启动本地网页：

```powershell
python app.py
```

浏览器打开终端显示的本机地址（默认是 <http://127.0.0.1:7860>）。界面只在本机访问，不会设置 `share=True`。

### 本地文件转录

选择“本地文件转录”，上传媒体、选择模型和语言，点击“开始本地转录”，然后下载 TXT 或 SRT。

### B 站链接导入已有字幕

1. 选择“B 站已有字幕”。
2. 粘贴完整单视频 BV 链接，例如 `https://www.bilibili.com/video/BV1.../`；短链、合集和空间页不支持。
3. 选择字幕语言。若未登录也能访问字幕，保持“不使用登录”即可。
4. 若 B 站提示字幕需要登录，在下拉框中**主动选择**已登录 B 站的 Chrome 或 Edge，点击“导入已有字幕”。VideoFlow 只让 yt-dlp 临时读取本机浏览器会话，不保存、显示、上传或提交 Cookie。
5. 查看时间戳结果，下载 TXT 或 SRT。

链接模式只获取平台已有字幕 JSON，不下载完整视频，也不会绕过登录、付费或 DRM 限制。西交 LMS 等课程回放 URL 需要学校登录，因此不支持直接粘贴；请按课程平台允许的方式获取媒体文件后，使用“本地文件转录”。

若 B 站返回“要求登录”“未返回可访问字幕”或该视频本来没有已有字幕，请改用下方的“播放中的网页/课程转录”：在浏览器中正常播放该视频，再录制本机扬声器声音并转写。

### 只能在线播放的课程或网页视频

选择“播放中的课程转录”，确认你有权为个人学习记录当前内容，点击“开始录制电脑声音”。然后在已经登录的课程网页中**正常播放**回放；结束时回到 VideoFlow 点击“停止录制并转录”。程序会录制 Windows 当前默认扬声器正在播放的声音，转录后自动删除原始临时 WAV，只保留你选择下载的 TXT/SRT。

这不是课程视频下载器：它不会读取 LMS 链接、账号、Cookie、页面内容或视频流，也不会规避任何访问控制。录制时系统其他播放声音也会被一并录入；请关闭通知和其他音频，并确认 Windows 的默认输出设备正是正在播放课程的扬声器/耳机。

也可以命令行转录：

```powershell
videoflow "D:\\media\\lecture.mp4" --model base --language zh --output-dir exports
```

未传 `--language` 时自动识别语言。模型不可用、FFmpeg 无法解码或文件不是有效媒体时，程序会给出可读错误信息。

## 测试

```powershell
python -m pytest
```

这些是无需下载模型或准备媒体的单元测试，覆盖 SRT/TXT、时间码、输入校验、转录结果转换、B 站链接校验和 BCC 字幕解析。真实转录已使用授权媒体验收；B 站登录态的成功字幕导入需由用户在自己的浏览器会话中手动验收。

## 演示验证

在 Windows、Python 3.13、CPU INT8 环境中，VideoFlow 已用一段经授权的 5 分 56 秒中文 MP4 完成端到端验证：`tiny` 模型生成了 120 个带时间戳的分段，并成功生成 UTF-8 TXT 与标准 SRT。该结果用于验证流程可运行，不代表识别准确率基准；`tiny` 适合快速初稿，术语和同音字较多时建议改用 `base` 或 `small` 比较质量与处理时间。

V0.2 还验证了 B 站公开链接的无登录失败路径：平台未提供公开字幕时，应用在 45 秒内给出登录/本地文件回退说明，不下载视频。受登录权限影响，真实成功导入需在用户自己的已登录浏览器中完成。V0.3 将该类失败原因直接显示在“处理状态”中，便于区分未登录、无字幕、网络超时和 URL 格式错误。

## 已知限制

- V0.1 没有说话人区分、字幕翻译、在线视频下载或批量队列。
- CPU 转录速度受电脑性能和模型大小影响；`base` 是普通电脑上的默认平衡选择。
- 模型首次下载需要网络；之后可从本地缓存使用。

更多规划和当前验证状态见 `docs/`。
